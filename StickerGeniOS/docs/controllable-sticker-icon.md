# Controllable sticker icon

Generated with the built-in image generation tool. The original transparent PNG is bundled in both the main app and Messages asset catalogs as `ControllableSticker`.

## Generation prompt

Use case: logo-brand. Generate a cartoon-style configuration UI icon for a playful iOS sticker app. Exactly three horizontal cream slider tracks with thick near-black outlines and round ends, one chunky circular knob on each track at different positions. Knob colors coral red, sky blue, and warm yellow. Flat clean cartoon geometry with confident bold outlines. Instantly recognizable conventional settings sliders, readable at 18 pixels. Centered square composition filling 85 percent of canvas, genuinely transparent background. Only the configuration sliders. No surrounding sticker border, no joystick, no characters, no text, no shadow, no extra decorations, no perspective. Minimal detail, cheerful polished cartoon style.
