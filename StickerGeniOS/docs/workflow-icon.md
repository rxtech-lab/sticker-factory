# Workflow steps icon

Generated with the built-in image generation tool. Bundled as `WorkflowSteps` in the main app and Messages catalogs. `PosterSymbol` uses this for `list.number` and the previously generated configuration sliders for `slider.horizontal.3`.

## Generation prompt

Use case: logo-brand. Generate one cartoon UI icon representing a step-by-step review workflow, to sit beside explanatory text in an iOS sticker app. A small cream checklist sheet with three bold horizontal lines and three coral, sky-blue and yellow circular check markers. Thick near-black outlines, softly rounded corners, simple front-facing flat cartoon style matching colorful configuration sliders. Minimal detail, legible at 20 pixels. Centered, fill 85 percent of square canvas, genuinely transparent background. No words, no numbers, no emoji, no surrounding sticker border, no shadows, no extra decoration.
